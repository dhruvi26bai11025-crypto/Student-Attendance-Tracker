# How to Run

1. Make sure that Python is installed on your computer.

2. Keep `main.py` and CSV data file in one project folder.

3. Open a terminal in the project folder.

4. Run the following command:

# python main.py

5. Select an option from the menu and follow the instructions.

6. Menu Options

1. Add Student

2. Mark Attendance

3. View Attendance

4. Low Attendance Report

5. Exit

6. Attendance Rule

Those students whose attendance percentage is below 75% are identified in the low-attendance report.
